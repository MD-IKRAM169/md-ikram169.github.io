# Md Ikram Tareq — Personal Portfolio Website

A responsive static portfolio website built for GitHub Pages.

## Publish free with GitHub Pages

1. On GitHub, create a **public** repository named exactly `md-ikram169.github.io`.
2. Upload the **contents of this folder** to the repository root (`index.html`, `styles.css`, `script.js`, `assets/`, etc.).
3. Commit the files to the `main` branch.
4. Open **Repository → Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait a few minutes and visit `https://md-ikram169.github.io/`.

## Update later

- Resume: replace `assets/MD_Ikram_Tareq_Resume.pdf` with your newest résumé, keeping the same filename.
- LinkedIn: if you change your LinkedIn custom URL, search `index.html` for the old URL and replace it.
- Projects: edit the project cards in `index.html` when your Banking Digital Channels Analytics project is ready.
- Text/style: change content in `index.html`; design lives in `styles.css`.
