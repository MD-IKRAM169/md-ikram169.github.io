# Md Ikram Tareq — Portfolio

Responsive static website for GitHub Pages. No build step, external JavaScript libraries, trackers or font downloads are required.

## Publish the replacement

1. Extract the website ZIP. Back up your current repository files first.
2. Open https://github.com/MD-IKRAM169/MD-IKRAM169.github.io and confirm the `main` branch.
3. Upload the **contents** of the extracted folder to the repository root, preserving the `assets/` and `assets/projects/` paths. Replace files with matching names. Do not upload the ZIP or the containing folder as a single item.
4. Commit with `Update portfolio website and six featured projects`.
5. Verify Settings → Pages still deploys from `main` and `/ (root)`. Do not change hosting if already working.
6. Check the deployment status in Actions, then visit https://md-ikram169.github.io/ and refresh.

## Files

- `index.html` — complete portfolio content, six projects and SEO metadata.
- `styles.css` — responsive layout, keyboard focus and reduced-motion support.
- `script.js` — mobile menu and footer year; page content also works without JS.
- `privacy.html` — short notice describing the supplied static website, not a legal compliance certification.
- `assets/projects/01.svg`–`06.svg` — conceptual workflow illustrations, not actual outputs or benchmark results.
- `assets/social-card.png` — social sharing image.
- `assets/profile.jpg` — user-provided portrait, optimized for web with image metadata removed.
- `assets/favicon.svg` — browser icon.
- `assets/MD_Ikram_Tareq_Public_CV.pdf` — new public-facing CV based on the updated portfolio facts. It is not a replacement for the previously approved role-specific application CVs.

## Privacy and maintenance

The public CV omits the personal phone number, full address, residence document details and student identifiers. The old `assets/MD_Ikram_Tareq_Resume.pdf` is not linked by the new site. If it contains personal information you no longer want public, remove it from the repository and assess Git history/cached copies separately. Do not publish private CVs, academic materials or research datasets without checking permissions.

The project links point to existing repositories; technical execution and third-party redistribution permissions are not independently established. The MAE-ViT metrics are historical, the environmental analysis is descriptive, and the road-safety dashboard data are UK records rather than Bavaria. Review German legal/privacy disclosure obligations for your own circumstances before public deployment.
